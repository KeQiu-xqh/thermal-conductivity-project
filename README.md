# PINN + 红外测量热导率项目

本仓库用于记录我使用树莓派 5、Thermal-90 热像仪与 PINN 方法进行热导率测量的学习与实验过程。

## 项目内容

本仓库当前主要包含：

- 树莓派设置与无显示器 SSH 连接
- Thermal-90 热像仪连接与配置
- 基本的 Linux 命令学习
- Git 和 GitHub 的使用学习
- Markdown 实验笔记
- 热像数据采集、保存与本地分析
- 后续 PINN 训练与热导率反演准备

## 当前进展（更新至 2026-04-03）

目前已经完成：

- 树莓派系统烧录
- 电脑通过热点和 SSH 连接树莓派
- 基本 Linux 命令与 Python 运行测试
- Thermal-90 正确接入树莓派 GPIO
- SPI / I2C 相关依赖安装与配置

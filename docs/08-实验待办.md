结论先说清楚：从你把 `.dat` 下载到 Windows 之后开始，后面大部分工作确实都可以在电脑上完成。但要“真的得到金属热导率”，你还差的不是再录视频，而是把原始热像数据变成“可用于反演的训练数据”，再跑一个 PINN 反演脚本，最后把反演出的热扩散率换算成热导率。当前仓库里已经有前两步，最后一步还没有整理成一个现成可直接跑的 `code/` 脚本。

从现在开始，完整流程应该这样走。

1. 把原始录像放进本地数据目录  
   你先把树莓派传回来的 `.dat` 放到 `data/raw/`。这个文件就是整段热像的逐帧温度矩阵，是后面所有分析的源头。  
   对应的脚本是 [view_dat.py](C:/Users/28146/Desktop/thermal-conductivity-project/code/view_dat.py) 和 [construct_training_data.py](C:/Users/28146/Desktop/thermal-conductivity-project/code/construct_training_data.py)。

2. 先用 `view_dat.py` 看这段数据值不值得继续做  
   运行：

```bash
python code/view_dat.py data/raw/<你的文件名>.dat
```

它会从 `.dat` 生成这些结果：

- `outputs/preview/<stem>_preview.gif`  
  整段热视频的动图回放，最直观地看温度变化过程和样品是否一直在画面里。

- `outputs/figures/<stem>_frames_compare.png`  
  选取几帧代表性画面的静态对比图，用来快速看热扩散前后变化有没有异常。

- `outputs/figures/<stem>_center_temp_curve.png`  
  画面中心点的温度随帧数变化曲线，反映中心像素的温升/降温过程。

- `outputs/figures/<stem>_center_roi_curve.png`  
  画面中心附近一个小区域的平均温度曲线，比单个像素更稳一点，适合看整体趋势。

- `outputs/figures/<stem>_hot_roi_curve.png`  
  热点附近 ROI 的平均温度曲线，重点看最热区域的温度变化，通常更接近真实热源影响。

简单记：
- `gif` 看全过程
- `frames_compare` 看关键帧
- `center_*` 看中心位置变化
- `hot_roi_*` 看热点区域变化


这些图的作用不是“出结果”，而是做质检和选 ROI：
- GIF 用来看样品有没有一直在画面里
- 多帧对比图用来看热扩散是否正常
- 中心点曲线和热区曲线用来看温升是否平滑、是否有抖动
- 你要在这一步决定，样品的哪一小块区域才是后面真正要建模的 ROI

3. 再用 `construct_training_data.py` 把热像整理成 PINN 可吃的数据  
   运行：

```bash
python code/construct_training_data.py data/raw/<你的文件名>.dat --x-min ... --x-max ... --y-min ... --y-max ...
```

   这一步会把原始帧序列变成结构化样本，输出：
   - `<stem>_train_data.npz`
   - `<stem>_train_data.csv`
   - `<stem>_train_meta.json`

   这一步的数据作用非常明确：
   - `npz` 里是训练输入 `inputs=[x,y,t]` 和目标温度 `targets=T`
   - `csv` 是逐点明细，方便你检查每个点的时间和坐标
   - `meta.json` 记录 fps、ROI 范围、温度统计等元信息

   这一步做完，你才算真正从“录像文件”进入“反演数据”。

4. 再跑 PINN 反演，得到的是热扩散率 `alpha`，不是热导率本身  
   这一段是你现在最需要补齐的核心步骤。当前仓库的 `code/` 目录里还没有一个现成的 PINN 反演脚本，所以这一步要么你自己补脚本，要么把论文/参考里的 PINN 思路整理成可执行代码。

   PINN 的输入通常就是上一步生成的 `npz`，外加物理约束：
   - 数据损失：让模型拟合你测到的 `T(x,y,t)`
   - 物理损失：让温度场满足热传导方程
   - 边界损失：让边界符合你的实验边界条件
   - 初值损失：让初始时刻符合实验初始状态

   这一阶段的输出通常是：
   - 训练损失曲线
   - 拟合出来的温度场
   - 学到的热扩散率 `alpha`

5. 由热扩散率换算成热导率  
   如果你走的是 PINN 路线，最终热导率不是直接“训练出来”的，而是由：

```text
k = rho * cp * alpha
```

   得到。  
   这里：
   - `rho` 是密度
   - `cp` 是比热容
   - `alpha` 是热扩散率

   所以你还需要知道样品材料的 `rho` 和 `cp`，这些通常来自材料手册、标准值或单独测量。

6. 重复多次实验，再给出最终结果  
   单次结果不够。你最后应该对同一样品做多次重复采集和反演，然后输出：
   - 平均热导率
   - 标准差或不确定度
   - 和文献值/理论值的对比

   这一步决定你的结果是不是能叫“完整的热导率测量”。

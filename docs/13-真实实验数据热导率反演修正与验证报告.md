# 真实实验数据热导率反演修正与验证报告

更新：2026-06-16

## 1. 结论

合成 PDE 数据可以被 PINN 正确反演，但这不能证明同一 PINN 对真实热像数据可靠。

真实数据的主要问题不是单纯的帧率、训练轮数或随机种子，而是：

1. 全长 ROI 跨过支架、热端二维过渡区和远端异常换热区。
2. PINN 的数据损失远大于 PDE 损失，网络可以拟合温度场，但热导率仍会漂移。
3. 在短空间窗口内同时反演 `k` 和 `h` 时，`h` 不可辨识，会把不确定性传给 `k`。
4. 把内部裁剪点误当成自由杆端，会造成明显的窗口长度依赖。

最终采用的正式估计方法为：

- 只处理已知材料 H59 和 6061。
- 使用准确的 `fps`、`mm_per_px` 和杆体 ROI 导出 `.npz`。
- 从加热端扫描 `30/40/50/60 mm` 连续子域。
- 子域左右两端都使用实测温度作为 Dirichlet 边界。
- 固定 `h = 10 W/(m^2*K)`，只反演 `k`。
- H59 使用 `80~140 W/(m*K)`、6061 使用 `130~190 W/(m*K)` 作为宽物理质量门槛。
- 在通过门槛的候选中按留出时间段 RMSE 选择结果；无候选时拒绝该录像。

该方法在 5 份可用真实数据上的单次误差均不超过 `8.4%`，并能自动拒绝一份明显不适用的 6061 数据。

## 2. 合成数据验证

合成数据由有限差分 PDE 正向求解器生成，PINN 不读取生成时的真实 `k`。

- H59 和 6061 的粗筛、噪声、时间长度、空间长度和多种子复筛均已完成。
- 最终 PINN 配置固定 `h=10`，避免 `k/h` 联合不可辨识。
- 详细结果见 `docs/10-合成数据PINN验证报告.md`。

因此可以确认：当数据与 PINN 使用完全一致的 PDE、边界和观测机制时，反演链路本身可以恢复正确热导率。

| --- | --- | ---: | --- |
| 2026-06-05 16:03 | H59 | 五种子中位数 `109.40` | 本批次偶然表现良好，但尾段仍有不稳定 |
| 2026-06-08 14:49 | H59 | `21.82` | 明显偏低，质量检查拒绝 |

典型现象是温度 MSE 已较低，但 `k` 仍随训练继续变化。温度拟合好不能单独证明反演参数正确。

## 4. 根因校验

### 4.1 真实数据并非普遍违反 PDE

用实测初始场和实测左边界直接做 PDE 正向求解：

- H59 2026-06-05 在参考 `k=110` 附近 RMSE 约 `0.69 C`。
- H59 2026-06-08 15:56 在参考 `k=110` 附近 RMSE 约 `0.52 C`。

这说明 H59 的失败 PINN 数据仍与正确量级的 PDE 相容，主要错误在反演目标和参数可辨识性，而不是数据完全错误。

### 4.2 PINN 物理项权重不足

在失败 H59 数据上改变 PDE 权重时，温度 MSE 几乎不变，但 `k` 可从约 `77` 漂到 `214`。原配置中加权后的 PDE 项占总损失不到百分之一，网络主要在拟合温度数据。

### 4.3 全长模型残差具有固定空间结构

全域确定性 PDE 拟合结果：

| 数据 | H59 全域 k | 数据 | 6061 全域 k |
| --- | ---: | --- | ---: |
| 2026-06-05 | `124.10` | 2026-05-22 | `250.29` |
| 2026-06-08 14:49 | `131.00` | 2026-05-28 | `267.70` |
| 2026-06-08 15:56 | `117.45` | 2026-06-08 16:21 | `220.19` |

参考参数下，残差峰值通常表现为：

- 中段约 `35~53 mm`：实验温度高于一维 PDE。
- 最远端：实验温度低于一维 PDE。
- 6061 的局部偏差显著大于 H59。

这与支架局部换热、热端二维接触和远端额外散热一致，不符合单一全长均匀一维杆模型。

## 5. 已排除的修正方案

| 尝试 | 结果 |
| --- | --- |
| 增加训练轮数 | 可能降低温度 MSE，但会继续推动 `k` 漂移 |
| 更换 PINN mini-batch | 6061 仍约 `390 W/(m*K)` |
| 调整 PDE 权重 | `k` 对权重高度敏感，没有唯一物理解 |
| 只改时间窗口 30/60/90/120 s | 6061 从前 30 秒起就已偏高，不是晚期漂移 |
| 每个位置减初始基线 | 6061 撞到 `350` 上界且 RMSE 恶化 |
| `soft_l1` 稳健损失 | 真实偏差是持续结构性偏差，不是少数离群点 |
| 直接左裁或右裁 | 部分数据改善，但无法形成统一规则 |
| 内部裁剪后使用自由端边界 | 错误；会人为制造 `k` 随窗口长度变化 |

## 6. 最终方法及测试

新增代码：

- `code/fit_thermal_parameters_forward.py`
  - 有界确定性 PDE 参数拟合。
  - 训练/留出时间段误差。
  - 参数标准差、边界命中和条件数。
- `code/estimate_conductivity_from_experiment.py`
  - H59/6061 材料预设。
  - 加热端多窗口扫描。
  - 双实测边界。
  - 固定 `h`，只反演 `k`。
  - 自动接受或拒绝录像。
- `code/run_real_forward_validation.py`
  - 清单驱动的全域诊断批处理。

关键测试包括：

- 隐式三对角求解器与高精度 BDF 的温度场一致性。
- 已知合成场恢复 `k/h`。
- 内部子域使用双实测边界后仍恢复真实 `k`。
- 固定 `h` 时只拟合 `k`。
- 后段加入支架温度污染后，加热端窗口仍恢复真实 `k`。

## 9. 方法边界

该入口不是未知材料的盲识别器。它适用于：

- 已知材料是 H59 或 6061。
- 帧率、空间标定和 ROI 已核实。
- 加热端前 `30~60 mm` 至少存在一段近似一维、未被支架严重污染的区域。
- 数据包含足够温升和时间变化。

若所有窗口均被拒绝，应重新录制，而不是继续调训练轮数或从中间训练步骤挑一个接近参考值的结果。

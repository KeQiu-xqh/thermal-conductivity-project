# Linux 命令行学习笔记

## 我现在到底在学什么

### 1. Linux

Linux 是树莓派运行的操作系统环境。
现阶段可以先把它理解成类似 Windows、macOS 那样的一套系统，只不过树莓派更多时候是通过终端来操作。

---

### 2. Shell / 终端命令

我在终端里输入的这些内容：

```bash
pwd
ls
cd
mkdir
sudo shutdown now
```

主要是命令行命令，用来和 Linux 系统交互。
我现在最常接触的是 Bash 风格的 shell 命令。

---

### 3. Python

Python 是编程语言。比如：

```python
print("hello")
```

这是在写程序，不是终端命令。

也就是说：

* 在终端里输入 `ls`，是在操作系统
* 在 `.py` 文件里写 `print("hello")`，是在写 Python 代码

---

### 4. Git

Git 是版本管理工具。比如：

```bash
git status
git add .
git commit -m "更新笔记"
git push
```

这些是 Git 命令，用来管理项目文件的修改历史，不属于 Linux 基础命令本身，但也常常在终端里使用。


---

## 我应该怎么学这些命令

我现在不需要系统学完整的 Linux。
我当前目标是：

**会用少量常用命令完成树莓派实验前期搭建、连接、记录和代码运行。**

所以更适合我的方法是：

1. 先理解命令的英文原意
2. 再理解它的功能
3. 记住最常见的写法
4. 记住它在实验中的使用场景

---

## 怎么查一条命令是什么意思

### 方法 1：先猜英文原意

例如：

* `cd` = change directory
* `mkdir` = make directory
* `shutdown` = 关机
* `whoami` = who am I

这种方法很适合初学阶段。

---

### 方法 2：用 `--help`

例如：

```bash
ls --help
mkdir --help
python3 --help
```

作用：快速查看这个命令有哪些常见参数和用法。

---

### 方法 3：用 `man`

例如：

```bash
man ls
```

作用：查看命令的手册页。
缺点是一开始会比较难读，所以前期我更适合先用 `--help`。

## 按实验场景学习命令

### 场景 1：我现在在哪个目录

#### `pwd`

**英文原意：** print working directory

**作用：**
显示当前所在目录。

**最常见写法：**

```bash
pwd
```

**在实验里什么时候用：**
当我不确定自己现在位于哪个文件夹时，用它确认当前位置。

---

### 场景 2：这个目录里有什么文件

#### `ls`

**英文原意：** list

**作用：**
列出当前目录下的文件和文件夹。

**最常见写法：**

```bash
ls
```

更常见的详细模式：

```bash
ls -l
```

**在实验里什么时候用：**
查看当前目录里有没有实验代码、图片、数据文件或笔记文件。

---

### 场景 3：我要进入另一个文件夹

#### `cd`

**英文原意：** change directory

**作用：**
切换到别的目录。

**最常见写法：**

```bash
cd docs
```

返回上一级目录：

```bash
cd ..
```

回到当前用户主目录：

```bash
cd ~
```

**在实验里什么时候用：**
进入项目目录、进入 `docs`、进入代码文件夹时都会用到。

---

### 场景 4：我要新建一个文件夹

#### `mkdir`

**英文原意：** make directory

**作用：**
创建新文件夹。

**最常见写法：**

```bash
mkdir test
```

**在实验里什么时候用：**
创建新的实验目录、数据目录、图片目录、代码目录。

---

### 场景 5：我要新建一个文件

#### `touch`

**英文原意：** touch

**作用：**
创建一个空文件；如果文件已存在，也可以刷新它的时间戳。

**最常见写法：**

```bash
touch test.txt
```

**在实验里什么时候用：**
快速创建一个空的 markdown 文件、python 文件或记录文件。

---

### 场景 6：我要编辑一个文件

#### `nano`

**英文原意：** nano（一个轻量文本编辑器的名字）

**作用：**
在终端中直接编辑文本文件。

**最常见写法：**

```bash
nano test.py
```

退出方法：

* `Ctrl + X`：退出
* 退出时如果提示保存，按 `Y`
* 然后按回车确认文件名

**在实验里什么时候用：**
在树莓派上直接修改 Python 文件、配置文件、实验记录。

---

### 场景 7：我要查看文件里的内容

#### `cat`

**英文原意：** concatenate（原本有“连接输出”的意思）

**作用：**
把文件内容直接显示在终端里。

**最常见写法：**

```bash
cat test.txt
```

**在实验里什么时候用：**
快速查看某个文本文件、配置文件或代码文件内容。

---

### 场景 8：我要复制文件

#### `cp`

**英文原意：** copy

**作用：**
复制文件或文件夹。

**最常见写法：**

```bash
cp a.txt b.txt
```

**在实验里什么时候用：**
备份代码、复制配置文件、复制实验数据。

---

### 场景 9：我要移动文件，或者给文件改名

#### `mv`

**英文原意：** move

**作用：**
移动文件；也常用于重命名文件。

**最常见写法：**

```bash
mv old.txt new.txt
```

**在实验里什么时候用：**
整理实验文件、给数据改名、把图片移到 `images` 文件夹。

---

### 场景 10：我要删除文件

#### `rm`

**英文原意：** remove

**作用：**
删除文件。

**最常见写法：**

```bash
rm test.txt
```

**在实验里什么时候用：**
删除无用文件、错误生成的测试文件。

**注意：**
删除后通常不能像图形界面那样轻松恢复，所以要谨慎。

---

### 场景 11：我想知道当前用户是谁

#### `whoami`

**英文原意：** who am I

**作用：**
显示当前用户名。

**最常见写法：**

```bash
whoami
```

**在实验里什么时候用：**
确认当前登录的是哪个账户，例如是不是 `piqio`。

---

### 场景 12：我想知道这台设备叫什么名字

#### `hostname`

**英文原意：** host name

**作用：**
显示当前设备的主机名。

**最常见写法：**

```bash
hostname
```

**在实验里什么时候用：**
连接树莓派、通过网络识别设备、排查 SSH 连接问题。

---

### 场景 13：我要退出终端连接

#### `exit`

**英文原意：** exit

**作用：**
退出当前终端会话。

**最常见写法：**

```bash
exit
```

**在实验里什么时候用：**
SSH 远程连接完成后安全退出。

---

### 场景 14：我要运行 Python 代码

#### `python3`

**英文原意：** Python 3

**作用：**
使用 Python 3 解释器运行 Python 文件。

**最常见写法：**

```bash
python3 test.py
```

**在实验里什么时候用：**
运行热像仪采集程序、测试脚本、数据处理代码。

---

### 场景 15：我要更新软件列表

#### `sudo apt update`

**英文原意：**

* `sudo` = superuser do
* `apt` = Advanced Package Tool
* `update` = 更新

**作用：**
更新软件包列表，让系统知道有哪些软件可以安装、升级。

**最常见写法：**

```bash
sudo apt update
```

**在实验里什么时候用：**
准备安装软件前，一般先执行这条命令。

---

### 场景 16：我要安装软件

#### `sudo apt install`

**英文原意：**

* `sudo` = superuser do
* `apt` = 软件包工具
* `install` = 安装

**作用：**
安装系统软件。

**最常见写法：**

```bash
sudo apt install python3-pip
```

**在实验里什么时候用：**
安装 Python 工具、驱动依赖、系统级软件。

---

### 场景 17：我要安全关机

#### `sudo shutdown now`

**英文原意：**

* `sudo` = 用管理员权限执行
* `shutdown` = 关闭系统
* `now` = 现在立刻

**作用：**
立即关机。

**最常见写法：**

```bash
sudo shutdown now
```

**在实验里什么时候用：**
结束实验后安全关闭树莓派，避免直接断电导致系统损坏。

## Git 命令：我在项目里最常用的 4 条

### `git status`

**作用：**
查看当前有哪些文件被修改了，哪些文件还没提交。

**最常见写法：**

```bash
git status
```

**在实验里什么时候用：**
每次准备提交前先看一下状态。

---

### `git add .`

**作用：**
把当前所有修改加入暂存区，准备提交。

**最常见写法：**

```bash
git add .
```

**在实验里什么时候用：**
写完笔记、改完代码后，把修改加入提交范围。

---

### `git commit -m "说明"`

**作用：**
创建一次新的提交记录。

**最常见写法：**

```bash
git commit -m "更新树莓派搭建笔记"
```

**在实验里什么时候用：**
完成一小段明确工作后进行一次提交。

---

### `git push`

**作用：**
把本地提交上传到 GitHub。

**最常见写法：**

```bash
git push
```

**在实验里什么时候用：**
本地提交完成后，把项目同步到 GitHub。

---

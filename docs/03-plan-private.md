# 正式实验采购清单

更新时间：2026-04-10

## 采购原则

- 直接按最终版实验路线采购，不再单独做“临时第一版实验”。
- 主样品回到一维导热目标：**金属丝 / 金属圆杆**。
- 金属条也可以买，但只作为热像调试、ROI 练习和备选样品，不作为主路线。
- 第一轮正式搭建先控制在中低温范围，建议样品表面约 `50-80°C`，降低胶带脱落和烫伤风险。

## 不建议优先买

- `0.2-1 mm` 极细金属丝：太难被 Thermal-90 稳定成像。
- 厨房电磁炉：控温和几何布局都不适合。
- 大尺寸金属板：会把问题变成二维/边界复杂问题。
- 镜面抛光样品：红外发射率低，测温容易飘。
- 单通道热电偶温度计：不能同时看热端和冷端。

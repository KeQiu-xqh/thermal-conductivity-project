## 当前阶段判断

目前已经完成了“树莓派 + Thermal-90 跑通”的关键阶段。

现在的状态不是单纯的环境配置，而是已经进入：

**热像数据采集与预处理阶段。**

也就是说，后续重点将从“设备能不能连上”转向：

- 如何稳定录制数据
- 如何选择合适的 ROI
- 如何把热像数据整理成可分析、可训练的格式
- 如何逐步过渡到正式导热实验

## 接下来的任务

### 第一部分：工程与仓库管理
- 学习如何创建 GitHub 仓库
- 学习本地仓库初始化、提交、推送流程
- 继续完善 Markdown 笔记结构

### 第二部分：实验数据链路
- 固定采集流程：录制 `.dat` 文件、命名、保存、整理
- 将热像数据转换为更清晰的矩阵/时间序列格式
- 在本地电脑继续完善可视化脚本
- 增加“时间轴（秒）”版本的温度曲线
- 比较中心 ROI 与热区 ROI 的差异

### 第三部分：正式实验准备
- 让热目标尽量位于视场中央，避免边缘热点干扰
- 固定热像仪位置、目标位置和采集距离
- 开始采集更标准的加热/冷却过程数据
- 设计固定监测 ROI，而不是只跟踪最热点像素

### 第四部分：PINN 与导热系数反演
- 将热像数据整理为训练输入
- 理清 `x, y, t, T` 数据结构
- 在电脑上实现初步训练代码
- 将实验数据与物理模型逐步对应起来

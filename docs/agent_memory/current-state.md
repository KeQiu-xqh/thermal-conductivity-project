## 当前关键判断

- 采集链路已经不是主要风险。
- 当前主要风险是样品 ROI、数据格式和物理模型是否与正式反演一致。
- 当前通用 `x, y, t -> T` 数据仍偏向热像 ROI 数据，不是正式一维导热反演数据。

## 2026-05-05 模型修正

- 已明确确认：原参考报告中的理想一维绝热 PINN 与真实实验边界条件不匹配，不能再作为正式模型。
- 当前正式路线调整为：`黑体化处理 + 改善根部热接触 + 一维含散热项非稳态模型 + 多参数 PINN`。
- 一维假设仍然保留，但必须把侧向散热和真实边界条件纳入。
- 裸金属热像测温不再视为可直接定量反演的数据源。
- 后续正式数据格式应从通用 `x, y, t -> T` 收敛为沿棒轴线或窄带平均后的 `x, t -> T`。
## 2026-05-11 实验器材更新

- 导热硅脂已到位，可开始做“加热台 -> 金属棒热端”的薄层耦合与压紧测试。
- 下一步不是把硅脂直接滴成一团使用，而是先在加热端接触面刮成极薄均匀层，再放置金属棒并施加稳定压紧。
- 当前风险从“缺少接触材料”转为“硅脂层过厚、接触面不平、压紧不足导致接触热阻仍然过大”。

- 但这组数据整体不表现为明显持续升温过程，更接近“已有热区下的小幅波动 / 轻微回落”，因此暂不适合作为正式加热响应数据。
- 当前下一步应优先改为：从更明确的加热起点开始录制，并固定样品、相机和热端装配，争取获得更清晰的单调升温过程。
## 2026-05-11 对 run01 的解释修正

- `thermal90-20260511-run01.dat` 不是“从冷态开始加热”的响应数据，而是“从加热台取下后单独观测金属棒冷却”的数据。
- 该组数据的主要用途应调整为：验证红外画面中能否识别金属棒位置、提取棒上表观温度分布、观察冷却趋势，而不是直接用于升温边界响应分析。
- 当前分析显示金属棒在画面中的主要区域约为 `x=10~66, y=41~43`，中段更热，两端更冷，符合一根横向样品棒的热像形态。
- 这组数据可支持“相对温度分布/冷却趋势”判断，但若样品表面发射率处理不足，绝对温度是否准确仍需接触式测温或黑体化处理交叉验证。
## 2026-05-11 run02/run03 新数据分析

- 已回传并分析两组新数据：`data/raw/thermal90-20260511-run02.dat`（加热）与 `data/raw/thermal90-20260511-run03.dat`（冷却）。
- 两组画面中的铝棒主轴都应按“竖直方向”理解，而不是横向；此前对 `run01` 的横向判断不适用于这两组新视频。
- `run02` 中可识别的是一段较细的竖直棒影，主区域约在 `x=45~49, y=8~59`；下方高温区主要是加热台/近热端区域，说明这组升温视频里看到的是远离热端的一段可见棒身，而不是完整热端。
- `run03` 中可识别的上方细棒区域约在 `x=38~45, y=0~45`，底部更粗更亮的区域可解释为导热硅脂/热端块；该组数据可区分“上方棒身冷却”和“底部热端块冷却”。
- 当前能稳定提取的是像素坐标下的相对距离和温度演化；若要进入正式 PINN，需要把像素轴 `y` 转成物理距离 `x`，并明确热端位置、样品直径、有效长度及起始/边界条件。

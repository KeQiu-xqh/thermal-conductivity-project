# Current State

更新：2026-05-22

## 当前主线

项目主线已经进入“基于黑体化铝棒数据做正式 PDE 版 PINN 回测，并逐步提高热导率结果可信度”阶段。

## 当前正式数据

- 原始数据：`data/raw/thermal90-20260522-run02.dat`
- 样品：6061 铝棒，`150 mm x 8 mm`
- 热台：`100 C`
- 室温：`25.0 C`
- 表面：哑光黑漆，建模发射率取 `0.95`

## 当前正式 ROI 与坐标

- 冷态起点：`frame 0`
- 帧率：`7 fps`
- 正式 ROI：`x=10~80, y=30~34`
- 热端方向：`left`
- 标定：`mm_per_px = 2.0`
- 主派生文件：`data/derived/thermal90-20260522-run02_rod_xt_data.npz`

## 当前正式模型

- 脚本：`code/train_pinn_1d.py`
- 方程：
  - `T_t = alpha*T_xx - 4h/(rho*cp*D)*(T-T_inf) - 4*epsilon*sigma/(rho*cp*D)*(T^4-T_inf^4)`
- 左边界：
  - 支座外第一列棒身像素温度曲线
- 右边界：
  - `none`
- 初始条件：
  - 前 `5` 帧实测平均温度分布

## 当前主结果

- 最终摘要：`outputs/models/thermal90-20260522-run02_pinn_phys_final_summary.json`
- `alpha = 6.99e-5 m^2/s`
- `h = 11.07 W/m^2/K`
- `k = 169.82 W/(m*K)`
- 温度场 `MSE = 0.371 C^2`

## 当前关键判断

- 这次回测中，最靠左的两列像素仍受支座热端串扰明显。
- 如果把左边界放在 `x=8`，会把热导率压低到约 `89 W/(m*K)`。
- 把正式 ROI 改成 `x=10~80` 后，结果抬升到约 `170 W/(m*K)`，更接近 6061 铝常见量级。

## 当前风险

- `mm_per_px` 仍是图像几何标定，不是外部标尺校准。
- 当前结论来自单次实验，重复性还没有统计。
- 左边界仍是表观边界，不是支座内部真实接触面温度。

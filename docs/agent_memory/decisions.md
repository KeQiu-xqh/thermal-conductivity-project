# Decisions

更新时间：2026-04-10

## 实验路线

- 当前主线采用“智能加热台 + 金属丝/金属圆杆样品 + Thermal-90 热像采集”。
- 金属条不再作为主样品，只作为热像调试、ROI 练习和备选样品。
- PTC 加热片 + MOS + GPIO 控制路线保留为备选，不作为最快复现实验的主路线。
- 原因：智能加热台更容易稳定控温，减少电路调试时间，更适合尽快完成完整实验复现。

## 样品路线纠偏

- 用户指出实验目标是一维金属丝导热系数测量，不能默认用铝条替代主样品。
- 后续采购与实验设计应优先使用直径 `3-4 mm`、长度 `200-300 mm` 的金属圆杆/粗金属丝。
- 过细金属丝虽然更接近教材表述，但 Thermal-90 分辨率有限，直径低于 `3 mm` 时 ROI 稳定性风险较高。
- Codex 后续不要再把“金属条优先”作为默认主线。

## 数据处理路线

- 先使用现有 `.dat` 数据读取脚本继续推进，不完全重写采集程序。
- 电脑端分析优先完善：
  - 帧号改为时间轴。
  - center ROI 与 hot ROI 同图比较。
  - 后续导出适合传统拟合和 PINN 使用的数据表。
- 正式实验前，逐步从“最热点 ROI”过渡到“固定样品 ROI”。

## 代码维护原则

- `code/` 当前主要存放 GPT 生成和电脑端分析脚本。
- `code_appendix/` 当前主要存放 PDF 附录代码和 Thermal-90 相关示例代码。
- 用户允许 Codex 修改 `code/` 和 `code_appendix/`，包括采集脚本和附录代码。
- 即使允许修改，也不轻易改坏已经跑通的树莓派采集链路。
- 遇到 bug、采集异常或环境问题，先查 skill 和已有记录，再决定是否改代码。
- 涉及树莓派、VNC 或 Thermal-90 真实设备的改动，改后需要记录结果。

# Decisions

更新：2026-05-05

## 实验路线

- 主线采用：`恒温加热台 + 金属圆棒样品 + Thermal-90 热像采集 + PINN 反演`
- 金属片不再作为正式主样品，只保留为热像调试或 ROI 验证用途。
- 正式样品优先使用 304 不锈钢圆棒，其次再做铝棒对照。

## 数据路线

- 原始热像数据保留为本地实验资产，不纳入 git。
- 训练数据从原始热像数据构建，不直接把普通视频作为源数据。
- 当前已完成固定矩形 ROI 数据构建，但正式反演前必须收敛为样品轴线 `x, t -> T` 数据。

## 模型与观测路线

- 不再采用原参考报告中的理想绝热一维 PINN 作为正式反演模型。
- 正式热像路线默认要求样品表面高发射率处理，优先采用哑光黑漆。
- 正式反演模型采用一维非稳态导热方程，并显式包含侧向对流散热；若温差较高则保留辐射项。
- 根部接触热阻优先通过“导热硅脂 + 压紧 + 实测根部温度边界”吸收，不在第一版里单独反演接触参数。
- PINN 第一版联合学习 `alpha` 与 `h`；`epsilon` 视表面处理情况固定为高发射率近似值。
- `SK8` 铝制支座 + `8 mm` 铝棒的装配，当前只作为热端夹具与短时热视频验证路线，不直接视为正式边界实现方案。
- 若后续继续沿 `SK8` 方案优化，优先目标是把它从“侧壁随机接触受热”改成“热端几何和接触条件更可描述、更可重复”的边界。

## 仓库整理路线

- `code/` 只保留当前正式运行脚本。
- `code_appendix/` 只保留参考或附录性质代码。
- 参考论文和旧方案资料不再保留在 `docs/` 主线中；当前只保留仍可执行、仍用于建模或状态交接的文档。
- 原始数据、派生数据、GIF、PNG 全部放入专门目录并默认不跟踪 git。

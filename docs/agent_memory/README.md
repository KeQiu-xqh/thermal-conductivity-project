# Codex 项目记忆区

这个文件夹用于保存 Codex 在本实验项目中的长期协作记忆，重点记录真实进展、困难、bug、路线决策和下一步动作。

## 使用规则

- 每完成一个阶段性进展后更新一次，而不是每天机械更新。
- 每次更新优先记录事实：做了什么、结果如何、遇到什么问题、下一步是什么。
- 重要实验路线变化、采购决策、关键 bug 修复，需要同步写入对应文件。
- 默认不在这里记录明文密码、热点口令、VNC 口令、私人账号信息；连接所需凭据由用户在会话中授权使用。
- 不把这个文件夹当成正式论文或报告，只作为项目推进时的工作记忆。

## 文件说明

- `current-state.md`：当前实验状态和已经跑通的链路。
- `bugs-and-fixes.md`：困难、bug、报错、定位过程和修复方式。
- `decisions.md`：实验路线、采购、数据处理策略等关键决策。
- `next-actions.md`：短期下一步动作，限制在 3-5 项。

## 更新触发

- 采集链路、VNC、数据分析、实验搭建出现阶段性进展。
- 修改关键代码或确认某个 bug 修复。
- 采购方案或实验路线发生变化。
- 正式实验数据采集完成一组，或分析结果足以影响下一步。

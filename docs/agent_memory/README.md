# Agent Memory

这里存放的是 **项目协作记忆**，不是正式实验记录。

用途分工：

- `current-state.md`：当前真实状态
- `bugs-and-fixes.md`：问题、原因、修复、验证
- `decisions.md`：已经稳定的关键决策
- `next-actions.md`：后续 3-5 条短期动作
- `session-handoff.md`：下一轮对话快速接续入口

更新原则：

- 只记录高价值、可复用、会影响下一步执行的内容
- 不记录密码等敏感信息
- 不把实验长篇叙事写进这里；正式过程写到 [`docs/06-experiment-log.md`](/C:/Users/28146/Desktop/thermal-conductivity-project/docs/06-experiment-log.md)

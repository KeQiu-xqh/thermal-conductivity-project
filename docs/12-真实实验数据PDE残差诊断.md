# 真实实验数据 PDE 残差诊断

更新日期：2026-06-16

## 诊断目标

判断 H59 真实数据反演失败究竟来自：

1. 实验温度场不符合当前一维导热 PDE；
2. 帧率、空间长度、散热或右端边界设置错误；
3. PINN 虽然拟合了温度，但没有严格满足 PDE。

## 方法

- 使用实测前 `5` 帧平均温度作为初始温场。
- 使用实测第一列温度作为随时间变化的左端边界。
- 固定 H59 参数：`rho=8500 kg/m^3`、`cp=380 J/(kg*K)`、直径 `8 mm`。
- 参考参数：`k=110 W/(m*K)`、`h=10 W/(m^2*K)`。
- 扫描：
  - `k = 60, 80, 100, 110, 120, 140 W/(m*K)`
  - `h = 0, 5, 10, 15, 20 W/(m^2*K)`
  - 右端绝热近似与 Robin 散热边界
- 对比实验温度场与有限差分/ODE 正向 PDE 温度场。

## 正向 PDE 对照结果

| 数据 | 参考 `k=110,h=10` RMSE | 网格扫描最佳结果 | 判断 |
| --- | ---: | --- | --- |
| `20260605-160328.dat` | `0.692 C` | `k=100,h=20,Robin`，RMSE `0.529 C` | 整体符合一维 PDE，远端实验温度略低 |
| `20260608-155612.dat` | `0.523 C` | `k=120,h=0,Robin`，RMSE `0.475 C` | 同样符合一维 PDE，且参考参数拟合优于成功数据 |

失败数据在固定 `h=10` 时的正向误差：

| `k W/(m*K)` | RMSE `C` |
| ---: | ---: |
| 60 | 1.151 |
| 80 | 0.830 |
| 100 | 0.597 |
| 110 | 0.523 |
| 120 | 0.485 |
| 140 | 0.518 |

该误差曲线明确支持 `k` 位于约 `110~120 W/(m*K)`，不支持 PINN 原结果 `76.72 W/(m*K)`。

## PINN 损失权重诊断

对 `20260608-155612.dat` 保持其他参数不变，只改变 PDE 权重：

| data 权重 | PDE 权重 | 反演 `k W/(m*K)` | 温度 MSE `C^2` | alpha 尾段波动 |
| ---: | ---: | ---: | ---: | ---: |
| 20 | 1 | 76.72 | 0.1173 | 31.08% |
| 20 | 3 | 88.38 | 0.1175 | 27.33% |
| 20 | 10 | 139.47 | 0.1199 | 9.86% |
| 20 | 100 | 213.88 | 0.1238 | 0.38% |

训练末期，原配置的损失分量约为：

- `20 * data_loss = 20 * 0.01618 = 0.324`
- `1 * pde_loss = 0.00181`
- `3 * bc_loss = 0.0281`
- `3 * ic_loss = 0.179`

PDE 项对总损失的直接贡献不到 `1%`。数据、边界和初始条件损失使用归一化温度误差，而 PDE 损失使用物理单位残差，当前固定权重并没有实现同尺度约束。

## 结论

1. `20260608-155612.dat` 实验数据本身没有明显错误；参考 H59 参数可以很好地正向复现实验温度场。
2. 当前 PINN 的主要问题是损失尺度不平衡和参数不可辨识：
   - 网络可以降低温度拟合误差；
   - PDE 约束相对过弱；
   - 改变 PDE 权重会让热导率从 `76.7` 大幅移动到 `213.9`，但温度 MSE 几乎不变。
3. 因此不能再把某个固定损失权重下的 PINN 最终 `k` 直接视为材料热导率。
4. 当前更可靠的真实数据反演基线应改为：
   - 对每个候选 `k/h` 做严格正向 PDE 求解；
   - 直接按实验温度 RMSE 选择参数；
   - PINN 暂时用于温度场近似或作为辅助方法，而不是唯一的参数反演器。
5. 若继续使用 PINN，需要引入无量纲化/自适应损失平衡，并用正向求解器验证 PINN 输出参数确实能复现实验温度场。

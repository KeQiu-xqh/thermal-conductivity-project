# 修订后半程实验方案

更新日期：2026-05-05

## 1. 修订背景

前期参考报告中的 PINN 部分采用了理想一维绝热热方程、零边界和高斯初始条件。这种写法适合教学演示，但与当前项目的真实实验不匹配，主要问题如下：

1. 一维假设可以保留，但细长金属棒暴露在空气中时，侧向对流散热不能忽略。
2. 裸金属在 Thermal-90 工作波段发射率低、反射率高，热像仪观测值不能直接视为真实表面温度。
3. 金属棒与加热台之间存在明显接触热阻，根部边界条件不能继续理想化处理。
4. 因此，原有“理想绝热 PDE + 教学 demo 级 PINN”不能作为正式实验方案。

本文件给出修订后的后半程实验路线，目标是在 10-15 小时内完成一套物理上自洽、工程上可落地、课程层面足够有说服力的闭环方案。

## 2. 正式实验目标

正式目标不再是复现参考报告中的理想 PINN 图，而是完成以下闭环：

1. 用热像仪稳定获取黑体化金属棒的表面温度场。
2. 从热像数据中提取沿棒轴线的 `x, t -> T` 数据。
3. 使用含散热项的一维非稳态模型约束 PINN。
4. 同时反演热扩散率 `alpha` 和换热系数 `h`。
5. 根据 `k = rho * c_p * alpha` 计算导热系数，并与材料手册值对比。

## 3. 器材购买清单

### 3.1 必买项

1. 哑光黑喷漆
   用途：将金属棒悬空段表面发射率提高到接近黑体，降低背景反射干扰。
   要求：优先买哑光黑、耐温型；不要选亮面漆。

2. 导热硅脂
   用途：填补金属棒与加热台之间的缝隙，降低接触热阻。
   要求：普通 CPU 硅脂即可，不需要高端型号。

3. 压紧重物
   用途：配合硅脂把根部接触端压紧，提升热耦合稳定性。
   形式：铁块、大垫片、平整玻璃块或小型金属压块均可。

4. 304 不锈钢圆棒，直径 3 mm 或 4 mm
   用途：作为正式样品的优先候选。
   理由：导热系数低于铝，更容易形成明显温度梯度，更适合课程实验中的热像采样与 PINN 反演。

### 3.2 建议购买项

1. 高温聚酰亚胺胶带
   用途：辅助固定样品或局部遮挡；不作为正式发射率修正的主要手段。

2. K 型热电偶或接触测温探头
   用途：测环境温度 `T_inf`，并优先测根部真实温度 `T_b(t)`。
   备注：第一版正式模型里，根部边界条件如果能直接测量，模型稳定性会明显提升。

3. 游标卡尺
   用途：测直径、有效长度、加热端长度，保证元数据完整。

## 4. 样品与搭建方案

### 4.1 样品建议

正式优先顺序如下：

1. 304 不锈钢圆棒，直径 3 mm，长度 200-300 mm。
2. 304 不锈钢圆棒，直径 4 mm，长度 200-300 mm。
3. 6061 铝圆棒，直径 3 mm 或 4 mm，作为对照组。

不建议把裸铝棒作为第一组正式样品。原因不是它不能导热，而是导热太快、温差分布更短更平，反而不利于低分辨率热像仪做稳定反演。

### 4.2 物理搭建

1. 将样品的一端约 2 cm 作为加热接触端。
2. 在接触端表面均匀涂抹导热硅脂。
3. 将该端平放在已预热的恒温加热台上。
4. 用重物压住接触端上方，使其接触稳定。
5. 样品悬空段保持直线，尽量水平或固定倾角，避免中途晃动。
6. 热像仪固定在支架上，视场中只保留样品和必要背景，避免人员在镜头前走动。

### 4.3 黑体化处理

1. 仅对悬空段喷涂薄层哑光黑漆。
2. 根部接触端可不喷或少喷，避免影响接触热阻。
3. 黑漆必须完全干燥后再做热像实验。
4. 若第一轮只能临时验证，可用高发射率黑胶带辅助，但正式数据优先使用喷漆样品。

## 5. 数据采集方案

### 5.1 采集对象

正式采集内容应包括：

1. 原始热像 `.dat` 文件。
2. 环境温度 `T_inf`。
3. 样品材料、直径 `D`、有效长度 `L`、加热接触长度 `L_b`。
4. 表面处理方式，例如“黑漆”或“黑胶带临时验证”。
5. 若可行，记录根部实测温度 `T_b(t)` 或至少稳态根部温度 `T_b`。

### 5.2 采集流程

1. 测量室温并记录为 `T_inf`。
2. 启动热像采集脚本，先记录 5-10 秒冷态背景。
3. 放置样品并开始受热，连续录制至近稳态。
4. 停止录制后立即回看 GIF，检查样品是否始终处在固定 ROI 中。
5. 仅保留视场稳定、样品边界清楚、热带连续的数据作为正式样本。

## 6. 修订后的物理模型

### 6.1 保留的一维假设

对于 3-4 mm 级金属圆棒，只要材料仍为金属，一般可认为截面温度近似均匀，因此保留一维模型：

$$
T = T(x,t)
$$

这里保留的是“一维空间建模”，不是“绝热边界”。

### 6.2 正式 PDE
推荐第一版正式模型采用：
$$ 
\rho c_p \frac{\partial T}{\partial t} =
k \frac{\partial^2 T}{\partial x^2} - \frac{4h}{D}(T - T_\infty) - 4 \epsilon \sigma \frac{(T^4 - T_\infty^4)}{D}
$$


等价写成以热扩散率 $\alpha = k / (\rho c_p)$ 为参数的形式：

$$
\frac{\partial T}{\partial t} =
\alpha \frac{\partial^2 T}{\partial x^2} - \frac{4h}{\rho c_p D}(T - T_\infty) - \frac{4 \epsilon \sigma}{\rho c_p D}(T^4 - T_\infty^4)
$$

说明：

1. 第二项是轴向导热。
2. 第三项是侧向自然对流散热。
3. 第四项是表面热辐射散热。
4. 若第一版训练不稳定，可先保留对流项，把辐射项作为第二版补充；但正式文档里应明确辐射项存在。

### 6.3 边界条件

推荐边界条件如下：

1. 根部 `x = 0`
   优先采用实测边界温度：
   $$
   T(0,t) = T_b(t)
   $$

2. 末端 `x = L`
   第一版可用绝热近似：
   $$
   \frac{\partial T}{\partial x}(L,t) = 0
   $$
   若后续需要更严谨，可改为端部对流/辐射混合边界。

3. 初始条件
   使用真实初始温度场，而不是高斯分布：
   $$
   T(x,0) = T_0(x)
   $$
   其中 `T_0(x)` 直接来自实验开始前若干帧平均值。

## 7. 数据处理格式修改

当前项目里的训练数据还是通用 ROI 版 `x, y, t -> T`。正式反演前应改成更贴近物理模型的数据格式：

1. 在样品 ROI 中识别金属棒中心线或中心带。
2. 沿轴线方向建立实际长度坐标 `x`。
3. 对轴线附近窄带像素做平均，得到每一帧的 `T(x)`。
4. 最终形成 `x, t -> T` 的规则网格数据。

推荐每条记录至少包含：

- `time_sec`
- `x_mm`
- `temperature_c`
- `frame_idx`
- `sample_id`

元数据文件至少包含：

- `material`
- `rho`
- `c_p`
- `diameter_mm`
- `effective_length_mm`
- `heated_length_mm`
- `T_inf_c`
- `emissivity`
- `surface_treatment`
- `fps`

## 8. PINN 修改方案

### 8.1 网络输入输出

1. 输入：`x, t`
2. 输出：`T_pred(x,t)`

不再把整个二维图像坐标 `x, y, t` 直接送进正式 PINN。

### 8.2 可学习参数

第一版建议：

1. `alpha` 设为可学习参数。
2. `h` 设为可学习参数。
3. `epsilon` 固定为已知高发射率近似值，例如 `0.95`。

如果后续证据表明根部边界仍不稳定，再考虑把根部有效边界参数单独建模，但不建议第一版就把接触热阻也一起反演。

### 8.3 损失函数

总损失建议由四部分组成：

$$
\mathcal{L} =
\lambda_d \mathcal{L}_{data} + \lambda_p \mathcal{L}_{pde} + \lambda_b \mathcal{L}_{bc} + \lambda_i \mathcal{L}_{ic}
$$

1. 数据损失 `L_data`
   约束 `T_pred(x,t)` 拟合实验提取的轴线温度。

2. PDE 损失 `L_pde`
   约束模型满足修订后的非稳态导热方程。

3. 边界损失 `L_bc`
   约束 `x=0` 的根部边界与 `x=L` 的末端边界。

4. 初值损失 `L_ic`
   约束 `t=0` 时刻的温度分布贴合实验真实初值。

### 8.4 PDE 残差

若采用 `alpha` 形式，PDE 残差可写为：

$$
R(x,t) =
\frac{\partial T}{\partial t} - \alpha \frac{\partial^2 T}{\partial x^2} + \frac{4h}{\rho c_p D}(T - T_\infty) + \frac{4 \epsilon \sigma}{\rho c_p D}(T^4 - T_\infty^4)
$$

训练目标是让 `R(x,t)` 在采样点上尽可能接近 0。

### 8.5 训练策略

1. 先在一组正式样品数据上做单样品训练，验证模型能否稳定收敛。
2. 先把 `rho`、`c_p`、`D`、`T_inf`、`epsilon` 固定。
3. 优先反演 `alpha` 和 `h`。
4. 训练后再根据
   $$
   k = \rho c_p \alpha
   $$
   计算导热系数。
5. 将 `k` 与材料手册值对比，给出相对误差。

## 9. 风险与控制

### 9.1 主要风险

1. 黑漆不均匀，导致局部发射率仍不稳定。
2. 根部接触不稳，导致 `T_b(t)` 漂移或重复性差。
3. 热像仪分辨率有限，轴线提取太窄时噪声大。
4. 同时反演 `alpha` 和 `h` 时，参数可能出现耦合。

### 9.2 控制策略

1. 黑体化后先做静态热像验证，确认表面亮度均匀。
2. 每次实验前记录相同的根部压紧方式和加热台设定温度。
3. 轴线温度采用窄带平均而不是单像素读取。
4. 第一版先用不锈钢样品验证流程，再扩展到铝样品。
5. 如果联合反演不稳，可先固定经验范围内的 `h` 做单参数 `alpha` 训练，再升级为双参数反演。

## 10. 建议执行顺序

1. 购买并到位：黑漆、硅脂、压重物、不锈钢棒。
2. 完成样品黑体化与固定搭建。
3. 采第一组正式黑体化数据。
4. 把数据处理脚本从 `x, y, t -> T` 改为 `x, t -> T`。
5. 实现修订后的 PINN 第一版。
6. 在单一材料上完成一次完整反演。
7. 再做重复实验与材料对比。

## 11. 最终结论

本项目后半程不应继续追求“把原参考报告跑通”，而应转向“做一套物理上站得住的低成本非接触导热反演方案”。正式路线的关键不是放弃一维，而是：

1. 修正观测模型：先让热像真正看到样品温度。
2. 修正控制方程：把侧向散热写进 PDE。
3. 修正边界条件：用真实根部边界代替教学模板。
4. 修正 PINN：从 demo 级模板升级为面向真实实验的数据约束模型。

这样得到的结果即使误差不是最低，也比直接沿用理想模型更可信，更适合作为课程实验的正式报告主线。

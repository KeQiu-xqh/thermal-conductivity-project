### 正式 PDE 版训练设置

- 脚本：`code/train_pinn_1d.py`
- 方程：
  - `T_t = alpha*T_xx - 4h/(rho*cp*D)*(T-T_inf) - 4*epsilon*sigma/(rho*cp*D)*(T^4-T_inf^4)`
- 左边界：
  - 支座外第一列棒身像素温度曲线，Dirichlet
- 右边界：
  - `none`
  - 原因：当前画面右侧只是可见子区末端，不是物理自由端
- 初始条件：
  - 前 `5` 帧实测平均温度分布
- 材料参数：
  - `rho = 2700 kg/m^3`
  - `cp = 900 J/(kg*K)`
  - `D = 8 mm`
  - `epsilon = 0.95`
  - `T_inf = 298.15 K`

### 关键训练输出

- 最终主结果：
  - `outputs/models/thermal90-20260522-run02_pinn_phys_final_pinn.pt`
  - `outputs/models/thermal90-20260522-run02_pinn_phys_final_history.json`
  - `outputs/models/thermal90-20260522-run02_pinn_phys_final_summary.json`
  - `outputs/figures/thermal90-20260522-run02_pinn_phys_final_pinn_loss_curve.png`
  - `outputs/figures/thermal90-20260522-run02_pinn_phys_final_pinn_alpha_h_curve.png`
  - `outputs/figures/thermal90-20260522-run02_pinn_phys_final_pinn_pred_heatmap.png`

### 当前最可信结果

- `alpha = 6.99e-5 m^2/s`
- `h = 11.07 W/m^2/K`
- `k = 169.82 W/(m*K)`
- 温度场 `MSE = 0.371 C^2`

### 对照结论

- 若使用更靠左的 ROI `x=8~80`，会得到：
  - `k ≈ 89.41 W/(m*K)`
- 将左边界右移两列到 `x=10~80` 后，得到：
  - `k ≈ 169.82 W/(m*K)`
- 说明最左边两列仍受支座热端串扰，若把它们误当作棒身边界，会明显压低反演热导率。

### 当前结论

- `run02` 已经能支撑一次带对流与辐射项的正式 PDE 版 PINN 回测。
- 当前最可信主版本是：
  - `7 fps`
  - `frame 0` 冷态起点
  - `ROI = x=10~80, y=30~34`
  - `measured` 初始条件
  - `right_bc_mode = none`
- 对 6061 铝而言，当前 `k ≈ 169.82 W/(m*K)` 已进入合理量级，可作为当前阶段的主结果。

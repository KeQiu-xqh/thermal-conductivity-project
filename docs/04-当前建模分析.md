# 当前建模分析

更新：2026-06-05

本文只保留当前仍然有效的建模理解：物理方程、ROI 选取、训练数据构建、PINN 学习方式、训练控制和结果解释边界。旧方案、采购建议和早期 demo 路线不再作为当前主线。

## 一、当前物理模型

### 1. 建模对象

当前主线把黑体化金属圆棒看作一维非稳态导热问题：

$$
T = T(x,t)
$$

这里的一维是指沿棒轴方向建模，不是绝热假设。金属棒暴露在空气中，侧向散热不能忽略。

### 2. 当前 PDE

当前 `code/train_pinn_1d.py` 使用的正式方程为：

$$
T_t =
\alpha T_{xx}
- \frac{4h}{\rho c_p D}(T - T_\infty)
- \frac{4\epsilon\sigma}{\rho c_p D}(T^4 - T_\infty^4)
$$

各项含义：

- `alpha`：热扩散率，PINN 学习得到。
- `h`：侧向自然对流换热系数，PINN 学习得到。
- `rho`：材料密度，由命令行参数给定。
- `cp`：定压比热容，由命令行参数给定。
- `D`：圆棒直径。
- `T_inf`：环境温度。
- `epsilon`：表面发射率，黑体化后近似固定为 `0.95`。
- `sigma`：Stefan-Boltzmann 常数。

热导率由下式计算：

$$
k = \rho c_p \alpha
$$

### 3. 边界和初始条件

当前正式处理：

- 左边界：第一列可用棒身像素温度曲线，作为 Dirichlet 边界。
- 右边界：`none`，不强行把可见右端当成理想自由端。
- 初始条件：前 `5` 帧实测平均温度分布。

重要限制：

- 左边界是表观边界，不是支架内部真实接触面温度。
- 热端附近常有二维过渡区，左端前几列可能不能直接进入正式 ROI。
- 远距离完整入镜时，右端可能混入铁架台旋钮或支架结构，必须裁剪。

## 二、ROI 选取逻辑

### 1. 基本原则

ROI 不是“画面里看见的整根棒”，而是适合一维建模的棒身区间。

选择 ROI 时优先满足：

- 避开左端热台 / 支架 / 接触过渡区。
- 避开右端旋钮、支架或背景异物。
- 高度方向取稳定窄带，通常为 `y=30~34` 附近。
- 保持时间轴从冷态或明确起始状态开始。
- 标定 `mm_per_px` 必须和当前构图一致。

### 2. 当前已知经验

`6061@100 C` 主结果：

- `2026-05-22 run02`：`x=10~80, y=30~34`，`k = 169.82 W/(m*K)`
- `2026-05-28 run01`：`x=0~80, y=28~32`，`k = 159.84 W/(m*K)`

`6061@140 C` 远距离/近距离批次：

- 远距离完整入镜时，`x>70` 可能混入铁架台旋钮。
- `run04/run05` 表明，右端裁到 `x_max=68` 且左端从约 `x_min=12` 开始时，结果能回到更合理量级。
- 当前推荐处理可暂定为 `x=12~68, y=30~34`，但仍需结合具体 ROI 图确认。

`H59@100 C` 支架标定批次：

- 新增第二支架距初始加热端支架约 `99 mm`。
- 视频坐标存在约 `4x` 显示缩放，不能直接拿视频坐标当 Thermal-90 原始像素坐标。
- 主 ROI 建议避开两个支架影响区，例如 `x=12~56/58, y=30~34`。

## 三、训练数据形态

### 1. 原始数据

原始 Thermal-90 数据保存在：

```text
data/raw/*.dat
```

`.dat` 是实验资产，不直接用普通视频替代。

### 2. 派生数据

训练前会从 `.dat` 提取 ROI 和温度场，输出到：

```text
data/derived/
```

常见文件：

- `<stem>_rod_xyt_data.csv`：逐点明细，包含 `x,y,t -> T`。
- `<stem>_rod_xyt_data.npz`：二维 ROI 训练数据。
- `<stem>_rod_xt_data.csv`：沿棒轴线或窄带平均后的 `x,t -> T` 明细。
- `<stem>_rod_xt_data.npz`：当前一维 PINN 主要使用的数据。
- `<stem>_rod_meta.json`：ROI、帧率、标定、温度范围等元信息。

### 3. `csv` / `npz` / `json` 的作用

- `csv`：给人检查的明细表。
- `npz`：给模型训练的数组包。
- `json`：记录数据集元信息，避免以后忘记 ROI、帧率和标定来源。

`x,t -> T` 数据的核心含义是：

```text
输入: (x, t)
输出: T
```

其中 `x` 是沿棒轴方向的位置，`t` 是时间，`T` 是对应温度。

## 四、PINN 学习方式

### 1. 输入输出

当前一维 PINN 输入：

```text
x, t
```

输出：

```text
T_pred(x,t)
```

模型同时通过数据误差和 PDE 残差约束温度场。

### 2. 可学习参数

当前主要学习：

- `alpha`
- `h`

固定或外部给定：

- `rho`
- `cp`
- `D`
- `T_inf`
- `epsilon`

### 3. 损失项

总损失由以下部分组成：

- 数据损失：约束预测温度贴合实验提取的 `T(x,t)`。
- PDE 损失：约束模型满足当前非稳态导热方程。
- 边界损失：约束左边界温度曲线。
- 初始损失：约束 `t=0` 附近温度分布。

判断训练是否可靠时，不应只看最终 `k`，还要看：

- loss 曲线是否继续下降
- `alpha` / `h` 是否稳定
- 温度场 MSE
- 预测热图和实验热图是否一致
- ROI 是否有物理污染

## 五、训练控制

`code/train_pinn_1d.py` 当前支持：

- `--lr-scheduler plateau`
- `--resume-checkpoint`
- `--lbfgs-steps`
- `--early-stop-window`

推荐流程：

1. 先用 Adam 长训练。
2. 记录 scheduler、loss、`alpha`、`h`。
3. 必要时从已有 checkpoint 接 LBFGS 微调。
4. 判断收敛时优先看 `_history.json` 中的 `stage/lr/loss/alpha_m2_s/h_w_m2k`。

示例：从已有 2000-step checkpoint 接 LBFGS：

```powershell
python code\train_pinn_1d.py data\derived\20260605_h59_100c_160328_x12_56_calib99mm\2000.0.0.000000--20260605-160328_rod_xt_data.npz --epochs 0 --resume-checkpoint outputs\models\20260605_h59_100c_160328_x12_56_calib99mm_e2000_pinn.pt --lbfgs-steps 300 --lbfgs-lr 0.5 --rho 8500 --cp 380 --diameter-mm 8 --t-inf-c 24.5 --output-stem 20260605_h59_100c_160328_x12_56_lbfgs_from_e2000
```

## 六、当前结果解释边界

### 1. `6061`

当前主结果仍以近距离、较干净视野的 `100 C` 批次为准：

- `2026-05-22 run02`：`k = 169.82 W/(m*K)`
- `2026-05-28 run01`：`k = 159.84 W/(m*K)`

这说明当前流程对 `6061` 已有初步重复性。

### 2. `304`

两次 `304` 结果约 `48~49 W/(m*K)`，明显偏离材料常见量级。当前更适合作为装置局限性诊断数据，不作为正式可信热导率结果。

主要问题不是训练不收敛，而是低导热材料更容易受到热端结构和二维传热影响。

### 3. `H59`

当前多组结果支持 `H59` 大约在 `90~100 W/(m*K)` 量级。

`2026-06-05` 支架标定批次的 2000 epoch 结果：

- `x=12~56`：`k = 95.55 W/(m*K)`
- `x=12~58`：`k = 90.34 W/(m*K)`

该批次对长度标定有价值，但新增支架本身引入二维边界影响，因此仍更适合作为标定和诊断数据。

### 4. 总体风险

- `mm_per_px` 仍是主要误差源之一。
- 左端边界是表观边界。
- 支架、旋钮、相机距离和 ROI 选择会显著影响结果。
- 后续正式对比材料绝对热导率时，应优先使用近距离、视野干净、ROI 远离支架的复现实验。

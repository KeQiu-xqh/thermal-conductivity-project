## 当前主结果

- 数据：`data/derived/thermal90-20260522-run02_rod_xt_data.npz`
- 模型输出：`outputs/models/thermal90-20260522-run02_pinn_phys_final_summary.json`
- 当前最可信参数：
  - `alpha = 6.99e-5 m^2/s`
  - `h = 11.07 W/m^2/K`
  - `k = 169.82 W/(m*K)`
  - `temperature MSE = 0.371 C^2`

## 关键判断

- 这次反演里最重要的修正，不是多跑 epoch，而是：
  - 把帧率修正为 `7 fps`
  - 不再把可见右边界误当成物理自由端
  - 不再把全场初始温度硬设为 `25 C`
  - 把左边界从 `x=8` 右移到 `x=10`，避开支座串扰最重的两列
- 在这些修正后，热导率从约 `89 W/(m*K)` 抬升到约 `170 W/(m*K)`，已接近 6061 铝的常见量级。

## 当前风险

- `mm_per_px = 2.0` 仍来自图像几何标定，不是外部标尺校准。
- 当前结果来自单次实验，缺少重复性统计。
- 左边界仍然是“表观边界”，并非支座-棒内部接触面的直接温度。

## 下一步建议

1. 在相同装配下再复现一组黑体化数据，验证 `k` 是否稳定落在同一量级。
2. 若要继续提高置信度，补一次外部长度标尺标定，替代纯直径像素估计。
3. 若要写正式结果，增加一组重复实验并比较 `alpha`、`h`、`k` 的离散度。

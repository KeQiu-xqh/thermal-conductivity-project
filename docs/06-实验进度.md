## 关键判断

- 这次反演里最重要的修正，不是多跑 epoch，而是：
  - 把帧率修正为 `7 fps`
  - 不再把可见右边界误当成物理自由端
  - 不再把全场初始温度硬设为 `25 C`
  - 把左边界从 `x=8` 右移到 `x=10`，避开支座串扰最重的两列
- 在这些修正后，热导率从约 `89 W/(m*K)` 抬升到约 `170 W/(m*K)`，已接近 6061 铝的常见量级。

- 当前判断：

  - 当前方法对 6061 铝的热导率反演已表现出初步重复性

## 当前风险

- `mm_per_px = 2.0` 仍来自图像几何标定，不是外部标尺校准。
- 当前结果来自单次实验，缺少重复性统计。
- 左边界仍然是“表观边界”，并非支座-棒内部接触面的直接温度。

## 下一步建议

1. 在相同装配下再复现一组黑体化数据，验证 `k` 是否稳定落在同一量级。
2. 若要继续提高置信度，补一次外部长度标尺标定，替代纯直径像素估计。
3. 若要写正式结果，增加一组重复实验并比较 `alpha`、`h`、`k` 的离散度。

## 2026-06-05 H59 支架标定补充

- 新增一组 `H59@100 C` 数据：`data/raw/2000.0.0.000000--20260605-160328.dat`。
- 这次在距离初始加热端支架约 `99 mm` 处增加第二个金属支架，用来做长度-像素标定。
- 视频显示坐标为第一支架右端 `x=4`、第二支架左端 `x=250`；结合 Thermal-90 原始热像中的支架位置，按约 `4x` 显示缩放换算得到 `mm_per_px = 1.60976`。
- 按视频首尾时间 `16:03:28~16:12:20` 和 `3205` 帧，修正帧率为 `6.02256 fps`。
- 为避开两个支架附近的二维影响，主 ROI 取 `x=12~56, y=30~34`。
- 500 epoch 快速结果曾低到 `58~60 W/(m*K)`，后续检查确认这是训练未充分收敛导致的低估，不作为正式结论。
- 2000 epoch 长训练结果：
  - `x=12~56`：`k = 95.55 W/(m*K)`，`MSE = 0.097 C^2`
  - `x=12~58`：`k = 90.34 W/(m*K)`，`MSE = 0.098 C^2`
- 当前判断：这组数据对标定很有价值；长训练结果与此前 H59 的 `~90~100 W/(m*K)` 判断基本一致，但第二支架附近仍有二维影响，正式主结果仍建议补避开支架的复现实验。

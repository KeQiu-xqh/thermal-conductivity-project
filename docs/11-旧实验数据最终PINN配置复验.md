# 旧实验数据最终 PINN 配置复验

更新日期：2026-06-16

## 统一配置

- 数据时长：优先取录制起点后的 `120 s`
- 网络：`64 x 4`
- Adam：`1500 steps`
- 网络学习率：`1e-3`
- 热扩散率学习率：`2e-3`
- PDE 配点：`1024`
- 损失权重：`data/pde/bc/ic = 20/1/3/3`
- 初始条件：实测前 `5` 帧平均温场
- 右边界：`none`
- 对流换热系数：固定 `h = 10 W/(m^2*K)`
- 单次筛查：`seed = 42`
- 有希望的数据再扩展到 `seed = 42~46`

## 当前结论

1. 当前统一配置并非对所有实测数据都能给出正确热导率。
2. `20260605-160328.dat` 是目前唯一同时表现出合理量级和多种子重复性的 H59 数据。
3. 参数尾段稳定不等于结果正确：
   - `20260608-162125.dat` 和 `20260610-192336_roi_ymean.csv` 都较稳定，但结果明显偏离材料参考值。
4. 后续正向 PDE 诊断表明，`20260608-155612.dat` 在 `k=110 W/(m*K)` 下可达到约 `0.52 C` 的整体 RMSE，因此该数据并未明显违背当前一维 PDE；其错误反演主要来自 PINN 损失尺度和参数可辨识性，而不是实验数据本身错误。
5. 后续数据先做单种子 `120 s` 筛查；只有落入材料合理范围的数据才继续多种子验证。

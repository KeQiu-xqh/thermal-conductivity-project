### derived数据说明

<stem>_train_data.npz
<stem>_train_data.csv
<stem>_train_meta.json

这三个文件是同一批数据的三种表达方式，作用不一样。

#### `csv` 是“明细表”，一行就是一个点、一个时刻的温度：

```text
frame_idx,time_sec,x,y,roi_x,roi_y,temperature_c
0,0.0,44,12,0,0,21.84
```

含义是：

- `frame_idx`：这是第几帧
- `time_sec`：这一帧对应的时间，单位秒
- `x`：这个点在整张热图里的横坐标
- `y`：这个点在整张热图里的纵坐标
- `roi_x`：这个点在 ROI 里的横坐标，从 0 开始
- `roi_y`：这个点在 ROI 里的纵坐标，从 0 开始
- `temperature_c`：这个点的温度，单位摄氏度

简单说，`csv` 就是在说：
“第 `frame_idx` 帧、时间 `time_sec` 时，热图中 `(x, y)` 这个位置的温度是多少。”
- x, y = 整张热图里的绝对坐标
- roi_x, roi_y = 你截出来的 ROI 里的相对坐标
  ```text
  roi_x = x - x_min
  roi_y = y - y_min
  ```

#### `npz` 是“训练用压缩包”，里面有两组核心数组：

- `inputs = [x, y, t]`
- `targets = T`

这里的意思是：

- `x`：空间横坐标
- `y`：空间纵坐标
- `t`：时间
- `T`：温度

所以一条训练样本就是：

```text
输入: (x, y, t)
输出: T
```

这就是 PINN 或其他模型最常用的形式。  
它不是按“帧”存，而是按“点 + 时间”存，方便模型学习温度场。

#### `json` 是“说明书 / 元信息”，记录这批数据的背景信息，比如：

- `fps`：每秒多少帧
- `interval_sec`：每一帧之间的时间间隔
- `frame_count`：总共多少帧
- `roi_shape`：ROI 的大小
- `roi`：ROI 在原图中的位置范围
- `temperature_min_c` / `max_c` / `mean_c`：这批数据的最低/最高/平均温度

这些是对数据集的描述，方便你以后知道：
“这批数据是怎么采出来的，ROI 选在哪，时间轴怎么换算，温度范围大概是多少。”

#### 总结：

- `csv` = 逐点明细
- `npz` = 给模型训练的输入输出数组
- `json` = 数据集说明和参数记录

如果你愿意，我下一条可以直接用你这三行 `csv` 例子，给你手工演示一遍它们是怎么变成 `npz` 里的 `inputs/targets` 的。

#### 示例
`construct_training_data.py` 会把每一帧热像里的每个像素点，转换成一条训练样本。它的核心规则很简单：`inputs = [x, y, t]`，`targets = temperature_c`。

也就是说，模型输入的是这个点在整张热图里的空间坐标 `x, y` 和对应时刻 `t`，输出的是这个位置的温度 `T`。`csv` 只是把这一过程展开成明细表，方便人检查；`npz` 则是把这些明细整理成模型可以直接训练的数组。


把 `csv` 变成 `npz` 时，程序不会再保留 `roi_x,roi_y` 参与训练，而是只保留 `x,y,t` 作为输入，`temperature_c` 作为输出。比如这三行：

```text
0,0.0,44,12,0,0,21.84
0,0.0,45,12,1,0,22.75
0,0.0,46,12,2,0,20.25
```

会变成：

```python
inputs = [
    [44, 12, 0.0],
    [45, 12, 0.0],
    [46, 12, 0.0],
]

targets = [
    [21.84],
    [22.75],
    [20.25],
]
```

所以 `npz` 里的 `inputs.shape` 会是 `(3, 3)`，`targets.shape` 会是 `(3, 1)`。这里的意思就是有 3 条样本，每条样本有 3 个输入量 `x,y,t`，对应 1 个输出量温度 `T`。

如果把整个 ROI 和多帧都展开，过程就是“先扫完第 0 帧的 ROI 中所有点，再进入第 1 帧，再扫第 2 帧……”。举个更完整的例子，假设 ROI 只有 2x2 大小，坐标范围是 `x=44~45`，`y=12~13`，一共有 2 帧，帧间隔是 1 秒。那第 0 帧会生成 4 条样本：

```python
[44, 12, 0.0] -> 21.8
[45, 12, 0.0] -> 22.1
[44, 13, 0.0] -> 21.5
[45, 13, 0.0] -> 21.9
```

第 1 帧再生成 4 条样本：

```python
[44, 12, 1.0] -> 22.0
[45, 12, 1.0] -> 22.4
[44, 13, 1.0] -> 21.7
[45, 13, 1.0] -> 22.2
```

最后合起来，`npz` 里就是一大批这样的点：

```python
inputs = [[x, y, t], ...]
targets = [[T], ...]
```

这就是 `npz` 的意义：
- 把热像从“按帧看的图像”转成“按点看的训练样本”。后面的 PINN 或其他反演模型，就是拿这些 `(x,y,t)->T` 样本去学习温度场，再进一步反推出热扩散率，最后用 `k = rho * cp * alpha` 得到热导率。

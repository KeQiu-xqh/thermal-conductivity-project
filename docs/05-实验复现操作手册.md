# 实验复现操作手册

更新：2026-06-05

用途：从连接 Raspberry Pi 到录制 Thermal-90 `.dat`、拷回 Windows、本地回看和记录实验信息，按顺序完整复现实验。

## 一、实验前确认

### 1. 硬件

- Raspberry Pi 5
- Thermal-90 Camera HAT
- Windows 电脑
- 手机热点或同一局域网
- VNC Viewer
- 金属圆棒样品
- 恒温加热台
- 样品支架 / 夹具
- 黑体化样品表面

### 2. 基本原则

- SSH 只用于登录、检查状态、拷文件、跑不需要图形界面的命令。
- VNC 桌面用于运行实时热像窗口。
- 不要在纯 SSH 终端里运行带图形窗口的 `thermal90_ir_temp.py`，否则容易出现 `could not connect to display` 或 Qt `xcb` 相关错误。
- 录制前先确认样品、热端、右端支架和背景都没有明显遮挡 ROI。

## 二、连接 Raspberry Pi

### 1. 连接网络

1. 打开手机热点或确认电脑与 Raspberry Pi 在同一局域网。
2. 给 Raspberry Pi 上电。
3. 在热点设备列表或路由器设备列表中找到 Raspberry Pi 的 IP。

### 2. Windows PowerShell 登录

```bash
ssh piqio@树莓派IP
```

如果第一次连接失败，等待 20 到 30 秒后再试一次。Raspberry Pi 刚启动时，SSH 服务可能还没完全起来。

### 3. SSH 基础检查

```bash
whoami
hostname
pwd
python3 --version
ls /dev/i2c*
ls /dev/spidev*
sudo i2cdetect -y 1
```

正常信号：

- 当前用户是 `piqio`
- Python 3 可用
- 能看到 I2C / SPI 设备节点
- `sudo i2cdetect -y 1` 能扫到 `0x40`

如果 I2C 检查不对，先不要录制，优先排查 Thermal-90 连接和系统设备状态。

## 三、打开 VNC 并检查热像

### 1. 打开 VNC Viewer

在 Windows 上打开 VNC Viewer，连接同一个 Raspberry Pi IP。

后续需要热像窗口的命令都在 VNC 桌面终端里执行。

### 2. 进入采集脚本目录

在 VNC 桌面终端中运行：

```bash
cd ~/experiment/code
```

### 3. 先看实时画面

```bash
sudo python3 thermal90_ir_temp.py
```

确认：

- 热像窗口能打开
- 样品位于画面中
- 热端、右端、支架和背景关系清楚
- 没有明显遮挡或大幅晃动

确认完按 `Ctrl + C` 停止。

## 四、正式录制

### 1. 开始录制

```bash
sudo python3 thermal90_ir_temp.py -r
```

录制时尽量保持：

- 样品不移动
- 相机不移动
- 人不要从镜头前经过
- 热台设定和室温记录清楚
- 尽量从冷态开始

### 2. 停止录制

```text
Ctrl + C
```

### 3. 查看树莓派上的文件

```bash
ls -lh ~/experiment/code
```

录制文件通常在：

```text
/home/piqio/experiment/code/
```

文件名一般类似：

```text
2000.0.0.000000--20260605-160328.dat
```

## 五、拷回 Windows

回到 Windows PowerShell，执行：

```bash
scp piqio@树莓派IP:/home/piqio/experiment/code/文件名.dat C:\Users\28146\Desktop\thermal-conductivity-project\data\raw\
```

示例：

```bash
scp piqio@10.169.92.7:/home/piqio/experiment/code/2000.0.0.000000--20260608-164759.dat C:\Users\28146\Desktop\thermal-conductivity-project\data\raw\
```

## 六、本地回看

在 Windows 项目目录执行：
- `cd C:\\Users\\28146\\Desktop\\thermal-conductivity-project`：切换到项目根目录，保证后续脚本的相对路径正确。
- `python code\\view_dat.py data\\raw\\文件名.dat`：运行 `view_dat.py` 脚本来解析 `.dat` 记录并生成可视化结果（不会修改原始 `.dat` 文件）。


重点检查：

- GIF 预览是否完整
- 棒身是否一直在画面内
- 热端是否连续升温
- ROI 附近是否混入支架、旋钮或其他异物
- 右端 `x>70` 是否出现铁架台旋钮污染

### 输出文件说明：
- `outputs/preview/<stem>_preview.gif`：将采集的热图序列合成为一个动画预览（`<stem>` 为原始文件名去掉扩展名），用于快速人工检查整体帧是否完整、样品是否始终入镜。
- `outputs/figures/<stem>_frames_compare.png`：若干关键帧的并排或对比图（原始热像与处理结果/标注对比），用于查看帧间差异、运动或伪影等问题。
- `outputs/figures/<stem>_center_temp_curve.png`：杆体中心像素或中心线位置的温度随时间曲线，常用于判断热端是否按预期升温以及升温曲线的连续性和平滑性。
- `outputs/figures/<stem>_hot_roi_curve.png`：热区（或指定 ROI）内的温度随时间曲线，通常表示 ROI 的平均或最大温度，用于后续热传导或 PINN 训练的数据提取与拟合质量判断。

- 其他提示：
	- `<stem>` 是指原始 `.dat` 文件名不含扩展名的部分，例如 `2000.0.0.000000--20260605-160328`。
	- 文中提到的 `右端 x>70` 是图像坐标（像素或列索引）范围提示：当 `x>70` 区域出现背景（如铁架台旋钮）污染时，应在后处理或裁剪 ROI 时排除该区域，以免影响温度曲线与拟合。
	- 检查要点：先看 GIF 确认无明显抖动或遮挡，再看 `frames_compare` 定位伪影，最后查看两个温度曲线判断加热是否连续且无突变（突变通常意味着测量误差或遮挡）。

## 八、当前 ROI 与分析提醒

- 不要默认把整段 `x=0~80` 都当成棒身。
- 远距离完整入镜时，右端可能混入铁架台旋钮，需先检查 `x>70`。
- 当前推荐优先检查 `x=12~68, y=30~34` 这类裁剪方案。
- `H59@100 C` 支架标定批次中，第二支架可能在原始热像 `x≈62` 附近，正式 ROI 应避开两个支架影响区。
- 录制后不要只看最终热导率，还要检查 ROI 图、`x-t` 热图、loss 曲线和 summary。

# H59 与 6061 合成 PDE 数据 PINN 验证设计

## 目标

建立一套可重复的合成数据验证流程，用独立有限差分求解器生成与当前 PINN 物理方程一致的温度场，再盲反演 H59 和 6061 的热扩散率 `alpha`、对流换热系数 `h` 与热导率 `k`。

首轮实验回答三个问题：

1. 多长的观测时间能够稳定识别材料参数。
2. 多长的可见空间能够提供足够的温度梯度信息。
3. Thermal-90 量级的高斯测温噪声会在何处使反演失效。

该流程还要作为后续调整 PINN 训练逻辑和超参数的固定基准，保证每次修改都能与同一组数据和评价指标比较。

## 范围

本轮包含：

- 材料：H59、6061。
- 正向模型：一维非稳态轴向导热、侧向对流和侧向辐射。
- 噪声：独立同分布高斯测温噪声。
- 扫描变量：时间长度、空间长度、噪声标准差、随机种子。
- 输出：兼容 `code/train_pinn_1d.py` 的 `.npz` 数据，以及机器可读的扫描结果和汇总图。

本轮不包含：

- 二维导热、支架干扰、接触热阻或空间相关噪声。
- `mm_per_px`、帧率、环境温度和边界温度的系统性标定误差。
- 使用材料预设范围帮助 PINN 选择答案。
- 在基准扫描完成前同时修改多项 PINN 逻辑。

## 物理模型

正向求解器使用当前 PINN 对应的方程：

```text
T_t = alpha*T_xx
      - 4h/(rho*cp*D)*(T-T_inf)
      - 4*epsilon*sigma/(rho*cp*D)*(T_K^4-T_inf,K^4)
```

其中辐射项使用 Kelvin 温标。材料真值固定为：

| 材料 | rho (kg/m^3) | cp (J/kg/K) | k 真值 (W/m/K) | alpha 真值 (m^2/s) |
| --- | ---: | ---: | ---: | ---: |
| H59 | 8500 | 380 | 100 | `100/(8500*380)` |
| 6061 | 2700 | 900 | 160 | `160/(2700*900)` |

两种材料共用首轮环境与表面参数：

- `h = 10 W/(m^2*K)`
- `D = 8 mm`
- `epsilon = 0.95`
- `T_inf = 25 C`

左边界使用确定性的平滑升温曲线，而不是瞬时阶跃，以接近热台实际响应并避免数值冲击：

```text
T_left(t) = T_inf + delta_T*(1-exp(-t/tau))
delta_T = 70 C
tau = 20 s
```

初始条件为整根样品 `T(x,0)=T_inf`。正向计算域长度至少为扫描最大空间长度，并在物理末端使用与正向模型一致的 Robin 散热边界。导出较短空间窗时只裁切观测区域，不改变原始正向解。

## 数值方法

正向端必须独立于 PyTorch PINN，使用 NumPy/SciPy 有限差分方法。采用方法线形式：

- 空间二阶中心差分。
- 时间积分使用 SciPy 刚性 ODE 求解器，如 `solve_ivp(method="BDF")`。
- 内部计算网格比观测网格更密。
- 先求高分辨率真值，再插值或降采样到约 `1.5 mm` 空间间隔和 `6 fps`。

这样能够避免正向生成器与 PINN 使用相同神经网络、自动微分或相同离散点造成的逆问题偏乐观。

每次生成时保存：

- 方程与数值方法版本。
- 全部材料、边界和环境真值。
- 内部网格、输出网格和求解器容差。
- 噪声种子与噪声标准差。
- 无噪声温度场和加噪温度场。

生成器应检查 CFL 无关的基本数值质量，包括有限值、合理温度范围、边界曲线一致性，以及网格加密后温度场差异小于设定容差。

## 扫描设计

首轮粗筛使用：

- 时间长度：`30、60、120、240、480 s`
- 空间长度：`30、50、70、90、110 mm`
- 噪声标准差：`0、0.05、0.1、0.2、0.5、1.0 C`
- 材料：H59、6061
- 每组 PINN 种子：1

粗筛共 `2*5*5*6 = 300` 组。合成噪声种子和 PINN 初始化种子必须分开记录。粗筛完成后自动选择复筛组合：

- `k` 相对误差在 `10%` 或 `20%` 阈值附近的组合。
- 从成功区进入失败区的相邻组合。
- 每种材料表现最好的若干组合。
- 存在明显多解、参数漂移或质量守卫拒绝的代表组合。

复筛将选中组合扩展到 5 个 PINN 种子。默认不对全部 300 组直接跑 5 次，以控制计算量。

## 数据接口

新增生成器输出应直接兼容 `load_xt_dataset()`，至少包含：

- `xt_grid_c`
- `inputs_xt`
- `temperature_c`
- `time_axis_sec`
- `x_axis_heat_px`
- `x_axis_mm`
- `boundary_temperature_c`
- `far_end_temperature_c`

额外保存 `metadata_json` 或等价结构，记录真值和生成参数。PINN 训练代码只能读取温度观测、坐标和已公开的实验常量；评价脚本才允许读取 `true_alpha`、`true_h` 和 `true_k`。

为防止真值泄漏：

- 扫描运行 PINN 时使用 `material_preset=custom`。
- 不设置 `expected_k_min` 和 `expected_k_max`。
- 合成实验不得依赖材料范围生成 `best_physical` 结果。
- 模型选择只允许使用与真值无关的训练稳定性、数据损失和 PDE 损失。

## 代码结构

计划新增：

- `code/generate_synthetic_pde_data.py`
  - 定义材料和边界配置。
  - 求解高分辨率正向 PDE。
  - 裁切时间/空间窗、降采样、加噪并导出 `.npz`。
  - 支持单次命令调用和固定种子复现。

- `code/run_synthetic_pinn_sweep.py`
  - 读取 JSON 配置并生成缺失数据。
  - 逐组调用现有 PINN 训练入口。
  - 支持断点续跑、失败记录、单组重跑和最大并发数。
  - 每个组合写独立目录，避免中断后丢失已完成结果。

- `code/analyze_synthetic_sweep.py`
  - 汇总真值、最终结果、推荐结果、质量守卫和训练历史。
  - 计算误差、成功率与多种子离散程度。
  - 自动选择复筛候选并输出清单。
  - 生成时间长度、空间长度和噪声三者的适用域图。

- `configs/synthetic_pinn_h59_6061.json`
  - 保存材料、方程、网格、扫描范围、PINN 基准参数和复筛规则。

- `tests/test_generate_synthetic_pde_data.py`
  - 验证边界、初值、输出格式、固定种子和网格收敛。

- `tests/test_synthetic_pinn_sweep.py`
  - 验证组合展开、任务标识、断点续跑、真值隔离和结果解析。

## 运行与可重复性

每个实验使用稳定的任务标识，由材料、时间窗、空间窗、噪声、数据种子、PINN 种子和配置摘要组成。任务状态分为：

- `pending`
- `running`
- `completed`
- `failed`

扫描器启动时检查已有输出：

- 完整且配置摘要一致时跳过。
- 输出不完整时重跑该任务。
- 配置摘要不一致时不覆盖旧结果，创建新实验批次。

基准扫描固定 PINN 网络结构、损失权重、优化器和训练步数。后续调参时复制配置并只改变一个因素，例如：

- `alpha_init` 或 `h_init`
- 数据、PDE、边界、初值损失权重
- 网络宽度或深度
- collocation 点数
- Adam 学习率与步数
- Adam 后是否接 LBFGS
- 参数约束或模型选择逻辑

每个变体都与基准使用相同合成数据文件，避免噪声重新采样造成混淆。

## 评价指标

每个任务至少计算：

- `abs(k_est-k_true)/k_true`
- `abs(alpha_est-alpha_true)/alpha_true`
- `abs(h_est-h_true)/h_true`
- 全温度场 MSE
- 参数尾段相对范围
- 最终数据损失和 PDE 损失
- 是否完成最低训练步数
- 是否通过不含材料范围的稳定性守卫
- 最终结果与训练过程中稳定平台结果的差异

复筛额外计算：

- 5 个种子的中位数误差
- 四分位距
- 最大误差
- 成功率

首轮把“适合 PINN 的数据”定义为：

- `k` 中位数相对误差不超过 `10%`
- 至少 `4/5` 个种子的 `k` 相对误差不超过 `20%`
- `alpha` 与 `h` 的尾段稳定性通过阈值
- 不出现温度拟合良好但参数持续漂移的情况

最终结果应同时用绝对时间和空间长度，以及无量纲量报告：

```text
Fo = alpha*t_max/L_obs^2
SNR = max(T-T_initial)/noise_sigma
```

噪声为零时 SNR 记为无穷大。

## 图表与结论

分析器至少生成：

- 每种材料、每档噪声下的“时间长度 × 空间长度”热力图，颜色表示 `k` 相对误差。
- 每种材料的成功率热力图。
- `Fo-SNR` 散点或分区图。
- 代表任务的 `alpha/h/k` 训练轨迹。
- 基准与后续 PINN 变体的成对误差对比表。

结论不能只给一个最佳组合，而应给出：

- 稳定成功区。
- 临界区。
- 明显失败区。
- H59 与 6061 的差异。
- 当前训练逻辑主要受时间信息、空间梯度还是噪声限制。

## 实施顺序

1. 实现并验证独立正向 PDE 求解器。
2. 导出一个 H59、一个 6061 的无噪声完整数据集。
3. 用当前 PINN 做小规模端到端 smoke test。
4. 建立扫描器、断点续跑和结果表。
5. 完成 300 组单种子粗筛。
6. 自动选择临界组合并完成 5 种子复筛。
7. 固化基准报告。
8. 之后每次只修改一个 PINN 因素并重复相同评价。

## 验收标准

- 同一配置和种子重复生成的数据逐元素一致。
- 无噪声数据满足初值、左边界和正向 PDE 数值残差检查。
- 网格加密测试证明观测温度对内部网格不敏感。
- 生成的 `.npz` 能被现有 PINN 直接读取。
- 扫描中断后可从未完成任务继续。
- PINN 运行阶段无法读取 `true_k`、`true_alpha` 和 `true_h`。
- 汇总结果能追溯到具体配置、数据种子、PINN 种子和模型输出。
- 最终能够给出 H59 与 6061 的时间窗、空间窗和噪声适用域，而不是仅给出个别最优结果。

# README 复试展示化整理设计

## 目标

将仓库首页整理为面向北京大学软件与微电子学院推免复试老师的项目介绍，使读者能在约 30 秒内理解研究问题、技术路线、主要结果和项目边界，并能继续通过目录结构定位真实代码与验证材料。

## README 结构

1. 项目标题与一句话摘要。
2. 复试速览：研究问题、个人工作链路、核心结果、最重要的局限。
3. 数据与方法总流程：Thermal-90 采集、ROI、温度场、PINN、确定性 PDE 验证。
4. 物理模型与参数反演：明确 PINN 学习热扩散率 `alpha`，再由 `k = rho * cp * alpha` 换算热导率。
5. 主要结果：区分 PINN 历史结果、合成验证和真实数据正式估计。
6. 仓库目录：按核心源码、配置、测试、文档、数据和输出说明用途，并标记复试优先阅读文件。
7. 最短复现流程：保留采集后数据处理、PINN 训练和确定性估计的精简命令。
8. 模型假设、局限与下一步。

## 内容原则

- 以当前代码为准，不将设计目标写成已实现功能。
- 不把 OpenCV 描述为温度标定或正式 ROI 算法。
- 不把 `k` 描述为 PINN 中直接训练的 `nn.Parameter`。
- 明确当前真实数据正式判断优先采用确定性前向 PDE 子域估计器。
- 保留 PINN 作为项目核心研究路线、合成验证对象和复试代码讲解重点。
- 不夸大 304 不锈钢结果；将其归入装置与模型局限性分析。
